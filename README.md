# PHYG 2026 — Phylogénie et génomique comparative

Material for the practical sessions (TME) of the course, Sorbonne Université.

## Getting started

Follow **[SETUP.md](SETUP.md)** once, before the first session (about ten minutes;
Windows users start with WSL2). It ends with

```sh
pixi run selftest   # checks that everything works
pixi run lab        # opens JupyterLab in your browser
```

If the self-test passes and JupyterLab opens, your machine is ready.
